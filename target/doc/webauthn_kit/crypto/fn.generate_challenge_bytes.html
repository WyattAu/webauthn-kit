pub fn generate_challenge_bytes() -> Vec<u8> ⓘ
Expand description

Generate 32 random bytes (256 bits of entropy) for a WebAuthn challenge.

Uses the operating system CSPRNG via ring::rand::SystemRandom.

§Security notes

Challenges MUST come from a cryptographically secure source. If the OS entropy source fails, this function panics rather than emit predictable challenges (a failed CSPRNG is unrecoverable for security purposes).
