Verify a COSE signature using the parsed public key.

§Security notes / threat assumptions

  • alg is matched strictly: ES256 requires an CosePublicKey::Ec2 key, RS256 requires CosePublicKey::Rsa; any mismatch is an error, never a fallback.
  • signed_data and signature are attacker-controlled. Verification uses ring’s constant-time implementations (ECDSA_P256_SHA256_FIXED, RSA_PKCS1_2048_8192_SHA256).
  • RSA keys smaller than 2048 bits are rejected by ring’s RSA_PKCS1_2048_8192_SHA256 parameters.

Returns Ok(()) if and only if the signature verifies over signed_data.
